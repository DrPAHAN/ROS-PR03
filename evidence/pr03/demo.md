# Демонстрация работы ноды patrol (PR03)

## Роли компонентов ROS 2
- `rclpy.init()`: Инициализирует коммуникационную среду ROS 2 (DDS) для этого процесса.
- `rclpy.spin()`: Блокирует выполнение, бесконечно обрабатывая обратные вызовы (callbacks) от подписок и таймеров, пока не придёт сигнал прерывания.
- `callback`: Функция, которая асинхронно вызывается при поступлении нового сообщения в топик. В нашей ноде она просто сохраняет последнюю позу.
- `Ctrl+C`: Генерирует сигнал `KeyboardInterrupt`, который корректно завершает `spin()`, позволяет вызвать `node.destroy_node()` и `rclpy.shutdown()` для чистой остановки.

## Разрыв и восстановление связи
1. **Сломано**: Запуск `ros2 run patrol patrol` создаёт издателя в топике `/patrol/cmd_vel` (из-за относительного имени). Turtlesim слушает `/turtle1/cmd_vel`. Связи нет, черепаха стоит.
2. **Починено**: Запуск с `--ros-args -r cmd_vel:=/turtle1/cmd_vel` перенаправляет вывод. Топик становится `/turtle1/cmd_vel`, turtlesim его видит и начинает двигаться.
3. **Замер**: `ros2 topic hz /turtle1/cmd_vel` показывает частоту ~10 Гц, что соответствует периоду таймера 0.1 с.
